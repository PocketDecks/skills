# PocketDecks skills

Agent skills for working on [PocketDecks](https://github.com/PocketDecks) repositories.

| Skill | What it covers |
| --- | --- |
| [pokemon-tcg-pocket-tier-list-pr-workflow](pokemon-tcg-pocket-tier-list-pr-workflow/SKILL.md) | Changing, reviewing and verifying pull requests on [pokemon-tcg-pocket-tier-list](https://github.com/PocketDecks/pokemon-tcg-pocket-tier-list), the Pokémon TCG Pocket tier list behind [pocketdecks.top](https://pocketdecks.top) |

## Install

Copy a skill folder into your agent's skills directory. Each folder holds a `SKILL.md` with its trigger description and instructions, a `references/` folder it loads on demand, and any helper scripts.
